# starrail_role_info

真寻机器人的星铁角色面板插件

展示漫游签证中角色的面板和伤害数据

## 使用

- 星铁绑定uidXXXX / 绑定星铁uidXXXX / 崩铁绑定uidXXXX / 绑定崩铁uidXXXX
- 星铁解绑 (别名: 崩铁解绑)
- XX面板 (例:希儿面板、希儿面板@CRAZYShimakaze、希儿面板104442596)
- 更新星铁面板 / 刷新星铁面板 / 更新崩铁面板 / 刷新崩铁面板 (可在末尾附 UID；不附 UID 时使用已绑定 UID)
- XX(头手身脚球绳)推荐 (例:希儿头推荐)
- 我的星铁角色 (别名: 我的崩铁角色)
- 他的星铁角色@CRAZYShimakaze (别名: 他的崩铁角色)
- 最强XX / 群最强XX (例:最强希儿；群聊使用)
- 最菜XX / 群最菜XX (群聊使用)
- XX评分排行 / XX评分榜单 (仅群聊，不带序号)
- XX伤害排行N / XX伤害榜单N (仅群聊，N 为从 1 开始的伤害项目序号)
- 遗器榜单 (别名: 遗器排行)
- 群遗器榜单 (别名: 群遗器排行)
- 重置最强XX (仅超级用户群聊可用，例:重置最强希儿)
- 检查星铁面板更新 (仅超级用户可用)

绑定 UID 必须是首位为 1-9 的 9 位数字；已有绑定时需先解绑再更换。更新同一 UID 有 60 秒冷却，`检查星铁面板更新` 会读取远程版本和更新说明。

## 评分、毕业与排行

- 角色卡中的总评分是角色遗器总分，按本地 `res/json_data/score.json` 的角色有效词条权重计算；光锥不计入遗器评分。数据不完整时面板返回的评分会带 `*`，不会参与群内最强/最菜记录。
- 单件遗器评级由本地遗器主词条、副词条和强化数据计算。`ACE`、`ACE*` 计入大毕业遗器，`SSS` 计入小毕业遗器；个人遗器榜单会显示这两个计数，最多保留评分最高的 20 件遗器。
- `XX评分排行` 读取群成员实时昵称、`qq2uid.json` 的 UID 映射和本地 `{uid}.json` 角色缓存中的已保存评分；按评分降序（同分按 QQ 升序）取前 16 名，不调用外部面板接口，也不保存独立榜单。
- 伤害排行命令中的 N 对应角色伤害表从上到下的第 N 个伤害项目，不计 `额外说明` 行；伤害榜单按该项目的期望伤害排序。伤害结果在命令执行时由当前角色缓存重新计算，缓存中的规则或属性不完整时该成员会被跳过。

## 伤害计算与数据

- 首次查询或显式更新时按 `mihomo.me`、`enka.network` 顺序获取漫游签证数据，并写入插件目录下的 UID 缓存；普通角色面板查询优先读取已有缓存，`更新/刷新...面板` 才会强制重新获取。
- 面板伤害计算使用插件内置的固定 Miao-Plugin 星铁规则快照及 Python runtime（revision: `afff386eb6b31bc70a98144c3bbfa884eaf5e621`），读取角色、行迹、星魂、光锥和遗器等缓存字段；不依赖运行时 Node 或外部 Miao-Plugin checkout。
- 伤害表列顺序为“暴击伤害”“期望伤害”，`Buff列表` 展示当前默认伤害项目的触发说明。快照没有对应角色规则、缓存字段缺失或规则执行失败时不生成伤害表，也不会进入伤害排行；该规则集不宣称覆盖所有角色和配置。
- 遗器位置推荐只遍历当前 UID 缓存的对应位置遗器，并按遗器评分取结果；不会从外部实时扫描账号背包。
